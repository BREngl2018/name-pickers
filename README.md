# Share

A cheerful, private random name picker for classrooms, teams, giveaways, and groups.

## Features

- Add names individually or paste comma-, semicolon-, or line-separated lists
- Pick one or several winners
- Optional no-repeat rounds
- Shuffle and reset controls
- Recent-pick history
- Automatic local saving with no account or server
- Responsive and keyboard-friendly interface

## Run locally

No build step is required. Open `index.html` in a browser, or serve the folder:

```powershell
python -m http.server 8080
```

Then visit <http://localhost:8080>.

## Privacy

Names remain in the browser's local storage and are never sent to a server.
